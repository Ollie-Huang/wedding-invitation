# 互動式數位喜帖

目前版次：**v0.6.0｜兩家之囍・全頁主題**

橫式優先的婚禮喜帖網站原型，包含四組兩段式拉條：輕拉切換主畫面，完整拉出則展開該章節。

## 目前內容

- 四組示範章節：序幕、故事、婚宴、回覆
- 滑鼠、觸控與鍵盤操作
- 電腦、iPad、手機自動縮放
- 行動裝置直向瀏覽時的轉向提示
- GitHub Pages 自動發佈流程
- LINE／訊息／社群分享用的專屬預覽圖
- 第二章朱紅漆器與霧金囍氣主題、Q 版新人與正式婚宴資訊
- 行動裝置依瀏覽器實際可見範圍等比例縮放，不受網址列壓縮裁切

## 之後可替換

主要文字、姓名、日期都集中在 `app/page.tsx` 開頭的 `chapters`；照片與動畫區目前使用版型預留區，正式素材確認後可逐組換入。

推送到 GitHub 的 `main` 分支後，請在儲存庫的 Settings → Pages 將 Source 設為 **GitHub Actions**，之後每次更新都會自動重新發佈。
