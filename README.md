# 互動式數位喜帖

目前版次：**v0.8.12｜原色圖示・無痕圓底**

直式滾動的婚禮喜帖網站，目前包含三個全螢幕章節：上下滑動會優雅吸附到下一章，拖拉或點擊狗狗緞帶即可展開完整內容。

## 目前內容

- 三個直式全螢幕章節：關於我們、兩家之囍、婚宴地點
- 滾動吸附、觸控滑動與鍵盤翻頁
- 電腦、iPad、手機依裝置寬度自動重新排版
- 黃金獵犬與長毛臘腸雙動作緞帶引導（第三頁改為直接點擊交通資訊）
- GitHub Pages 自動發佈流程
- LINE／訊息／社群分享用的專屬預覽圖
- 第二章恢復朱紅、霧金與照片漸層主題，並保留正式婚宴資訊
- 第三章採冷灰藍酒店導視風格，包含路線圖、地圖、聯絡資訊與四種交通切換
- 行動裝置依瀏覽器實際可見範圍等比例縮放，不受網址列壓縮裁切

## 之後可替換

主要文字、姓名、日期都集中在 `app/page.tsx` 開頭的 `chapters`；照片與動畫區目前使用版型預留區，正式素材確認後可逐組換入。

推送到 GitHub 的 `main` 分支後，請在儲存庫的 Settings → Pages 將 Source 設為 **GitHub Actions**，之後每次更新都會自動重新發佈。
